☁️ Configuration Cloud Supabase
Synchronisez vos données entre plusieurs appareils
Comment obtenir vos clés Supabase :
1. Allez sur supabase.com → créez un compte gratuit
2. Créez un nouveau projet
3. Allez dans Settings → API
4. Copiez l'URL du projet et la clé anon/public
5. Collez-les ci-dessous et cliquez Tester
Format : https://xxxxxxxxxx.supabase.co
Clé publique (anon key) — jamais la clé service_role
Nom unique pour identifier vos données sur Supabase. Identique sur tous vos appareils.
📋 SQL à exécuter dans Supabase (une seule fois) 
CREATE TABLE IF NOT EXISTS smp_data (
  shop_id TEXT PRIMARY KEY,
  items TEXT, sales TEXT, users TEXT,
  expenses TEXT, returns TEXT,
  loyalty TEXT, commissions_paid TEXT,
  suppliers TEXT, cash_init NUMERIC DEFAULT 0,
  updated_at TIMESTAMPTZ DEFAULT now()
);
ALTER TABLE smp_data ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public_access" ON smp_data
  FOR ALL USING (true) WITH CHECK (true);
